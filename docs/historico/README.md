# Histórico do início do projeto

Instruções usadas para começar o porte do RESET EXPLODE para Linux com assistentes de IA (outubro de 2026), quando a organização
ainda se chamava Bismuth Technology. Ficam só como registro; o que vale hoje está em `AGENTS.md`, `CLAUDE.md` e em `docs/`.

- `PROMPT-CODEX-ILMENYX-BISMUTH.md`: pedido inicial de identidade, governança e atribuição (2026-10-21).
- `AGENTS-RESET-EXPLODE-LINUX.md` e `RESET-CODEX-KIT-LINUX.zip`: o primeiro kit de instruções do porte (2026-10-20).
- `sem-teste-registro-ate-2026-11-08.md`: registro completo de testes pendentes e defeitos corrigidos, incremento a incremento, até
  2026-11-08. A lista atual fica em `Sem_teste.md`, na raiz.
