# Ilmenyx — arquivos principais

Copiados do kit (não edite aqui; regenere e rode `python3 source/destaques.py`).

| Pasta | Use para |
|---|---|
| `logo/` | README, site, tela Sobre: fundo escuro ou claro; preto/branco para uma cor |
| `simbolo/` | Avatar, marca-d'água, materiais |
| `app/` | Dentro do software: ícone da janela, `.desktop`, ícone de app, `Palette.cs` (paleta oficial claro/escuro) |
| `app/hicolor/` | Ícones do sistema Linux (copie para `~/.local/share/icons/hicolor` ou `/usr/share/icons/hicolor`) |
| `web/` | Favicon, `.ico` e cores em CSS |
| `interface/` | Telas de referência da estética (Material 3 + acabamento Apple) |
| `Manual-Ilmenyx.pdf` / `.md` | Regras de identidade, cores, tipografia e interface |
