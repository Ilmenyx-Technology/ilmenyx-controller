## Janela só de Jogos
- **Atalho "Jogos — Ilmenyx Controller"** abre uma janela própria, só com os jogos, sem o monitor nem o ícone da bandeja.
- **Vitrine:** jogo escolhido em destaque (hero) com dados reais, capas largas, filtros, busca e Recentes, e a gaveta
  "Configurações do jogo" com **Gerenciar** no topo.
- **Abas:** Jogos, Conquistas, Compatibilidade, "Jogo não abre?" e "Meu PC roda isso?".
- **Tempo jogado** guardado a cada vez que o jogo é aberto pelo Ilmenyx (só existe depois de jogar por ele).
- **Ajustes compatíveis com versões futuras:** o `settings.json` mantém campos que esta versão ainda não conhece.

## Estilo console
- Fundo ambiente com o tom da arte do jogo (sem tom no tema claro), relógio, capa focada com anel branco e botão
  **Jogar** em pílula branca.
- **Conquistas** como troféus: cartões com anel dourado, cabeçalho de troféus e "última há N dias" quando há horário.
- **Meu PC roda isso?** com veredito grande e medidores com marca de mínimo e recomendado.
- **Nome em todas as capas** da biblioteca (os não escolhidos mais apagados).

## Uma janela só entre pacotes
Com o Ilmenyx aberto (inclusive escondido na bandeja), abrir outro pacote (Flatpak, AppImage ou pasta) traz de volta a
janela que já está aberta, em vez de abrir uma segunda. Durante uma atualização, uma versão antiga e uma nova abertas ao
mesmo tempo não se enxergam.

## English

A games-only window in console style, a single window across packages, and redesigned Achievements and "Can my PC run it?" pages.

**Download:** `Ilmenyx-Controller-0.35.0-x86_64.AppImage` is recommended (`chmod +x` and open it; every feature). The `.flatpak`
installs with `flatpak install --user`; some features are still untested there. Every file is GPG-signed (fingerprint above).
Already on 0.33.1 or newer? Click the version in the corner of the sidebar and **Update now**.

**Games window:** a "Games — Ilmenyx Controller" shortcut opens a window with games only (no monitor, no tray icon): a showcase
with the chosen game as a hero, wide covers, filters, search, Recents and a game settings drawer; tabs for Games, Achievements,
Compatibility, "Game won't open?" and "Can my PC run it?". Play time is recorded when a game is opened through Ilmenyx.
`settings.json` keeps fields this version does not know yet.

**Console style:** ambient background tinted by the game art, clock, white focus ring, white **Play** pill, trophy-style
Achievements, a big verdict with minimum/recommended meters in "Can my PC run it?", and names on every cover.

**One window across packages:** opening another Ilmenyx package while one is running (even hidden in the tray) brings the
existing window back instead of opening a second one.

**Not yet tested:** visual approval by the maintainer with real Steam art, light theme and X11/GNOME; game shortcuts in every
package format; the new Flatpak with a native instance already running.
