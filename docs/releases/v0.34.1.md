## Correção
- **Ícone da área de notificação no Flatpak:** na 0.34.0 o ícone aparecia com o logo clareado e só com a opção "Sair". Faltava uma
  permissão no pacote para o ícone se registrar no sistema; sem ela, entrava um ícone de reserva antigo. Agora o menu com o estado do
  PC e os atalhos aparece, e o logo vem com a cor certa. AppImage e pacote em pasta não tinham o problema.

Tudo da 0.34.0 continua: detalhe dos cartões da Visão geral, Proton/Wine e prefixo por jogo, Baixar versão…, uma só cópia do app.

## English

Fix for the notification-area icon in the Flatpak build.

**Download:** `Ilmenyx-Controller-0.34.1-x86_64.AppImage` is recommended (`chmod +x` and open it; every feature). The `.flatpak`
installs with `flatpak install --user`; some features are still untested there. Every file is GPG-signed (fingerprint above).
Already on 0.33.1 or newer? Click the version in the corner of the sidebar and **Update now**.

**Fix:** in 0.34.0 the Flatpak's tray icon showed a washed-out logo and only "Quit". The package lacked a permission for the icon to
register with the desktop, so an old fallback icon was used. The menu with the PC's state and shortcuts now shows, with the right
logo colours. The AppImage and the folder package were not affected.
