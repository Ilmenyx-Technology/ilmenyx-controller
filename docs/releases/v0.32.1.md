## Qual baixar
| Arquivo | Para quem |
|---|---|
| `Ilmenyx-Controller-0.32.1-x86_64.AppImage` | **Recomendado.** Um arquivo só: `chmod +x Ilmenyx-Controller-0.32.1-x86_64.AppImage` e abrir. Todos os recursos. |
| `Ilmenyx-Controller-0.32.1-x86_64.flatpak` | Quem prefere Flatpak: `flatpak install --user Ilmenyx-Controller-0.32.1-x86_64.flatpak`. Alguns recursos ainda não foram testados nele (`docs/flatpak.md`). |

Cada arquivo tem `.sha256` e assinatura GPG `.asc` (chave `ilmenyx-release-key.asc`, impressão digital
`3D97 1657 2A39 8DCD D0CF  F0EE 733D 2EC7 8436 DCE8`; como conferir: `docs/assinatura-gpg.md`). Fontes GPL que vão nos pacotes:

**Já tem o Flatpak 0.32.0?** Baixe o novo arquivo e rode `flatpak install --user --reinstall Ilmenyx-Controller-0.32.1-x86_64.flatpak`.

- **Flatpak sem ícone:** os ícones iam para a pasta errada dentro do pacote e o menu de aplicativos mostrava um "?". Agora ficam no

- **Também em Utilitários:** o Ilmenyx aparece em Utilitários, além de Sistema, no menu de aplicativos (Flatpak, AppImage e pacote em
  pasta).
- `Sem_teste.md` reescrito: o que já foi testado em hardware real e o que ainda falta, por área, com como ajudar.

## English

Flatpak fix: Ilmenyx now shows its icon in the application menu.

**Download:** `Ilmenyx-Controller-0.32.1-x86_64.AppImage` is recommended (`chmod +x` and open it; every feature). The `.flatpak`
installs with `flatpak install --user`; some features are still untested there. Every file is GPG-signed (fingerprint above).
Already on the 0.32.0 Flatpak? Download the new file and run `flatpak install --user --reinstall Ilmenyx-Controller-0.32.1-x86_64.flatpak`.

**Fixes:**
- **Flatpak without an icon:** the icons were placed in the wrong folder inside the package, so the application menu showed a "?".
  They now live in the `hicolor` theme, where the menu looks for them. The symbolic (monochrome) icon is now square, as the theme requires.
- **Also under Utilities:** Ilmenyx is listed under Utilities as well as System (Flatpak, AppImage and folder package).
- `Sem_teste.md` rewritten: what has been tested on real hardware and what is still missing, by area, with how to help.
