Primeira versão com o repositório **público**: agora qualquer pessoa pode baixar, relatar problemas e acompanhar o projeto.

> **Pré-lançamento.** Validado em hardware real, mas ainda não em todas as distros e GPUs (`Sem_teste.md`).

## Qual baixar
| Arquivo | Para quem |
|---|---|
| `Ilmenyx-Controller-0.32.0-x86_64.AppImage` | **Recomendado.** Um arquivo só: `chmod +x Ilmenyx-Controller-0.32.0-x86_64.AppImage` e abrir. Todos os recursos. |
| `Ilmenyx-Controller-0.32.0-x86_64.flatpak` | Quem prefere Flatpak: `flatpak install --user Ilmenyx-Controller-0.32.0-x86_64.flatpak`. Alguns recursos ainda não foram testados nele (`docs/flatpak.md`). |
| `Ilmenyx-Controller-0.32.0-linux-x64.tar.gz` | Pacote em pasta (técnicos). |

Cada arquivo tem `.sha256` e assinatura GPG `.asc` (chave `ilmenyx-release-key.asc`, impressão digital
`3D97 1657 2A39 8DCD D0CF  F0EE 733D 2EC7 8436 DCE8`; como conferir: `docs/assinatura-gpg.md`). Fontes GPL que vão nos pacotes:
`OpenRGB-1.1-source.tar.gz`, `umu-launcher-1.4.4-source.tar.gz`, `python-xlib-0.33.tar.gz`.

## Novidades
- **Área de notificação (opcional):** ao minimizar, o Ilmenyx vira um ícone perto do relógio, com Abrir, Pausar monitor e Sair.
  Só esconde a janela quando o ambiente mostra a área de notificação (no GNOME, com a extensão AppIndicator).
- **Aviso de CPU quente (opcional):** notificação quando a CPU fica acima do limite (80 a 95 °C) por 20 segundos seguidos. Picos
  rápidos de turbo não geram aviso.
- **Aviso de versão nova (opcional, pedido uma vez):** consulta as releases do GitHub uma vez por dia; a versão no menu lateral vira
  link para a página de download.
- Todas essas opções ficam em **Requisitos e sobre › Preferências** e vêm desligadas.
- Central de ajuda com as novas perguntas e o custo real do monitor (~3 % de um núcleo parado), nos três idiomas.
- Repositório renomeado para `ilmenyx-controller`, README em inglês e português, formulários para relatar problemas e ideias.

## English

First release with the repository **public**: anyone can now download it, report problems and follow the project.

**Download:** `Ilmenyx-Controller-0.32.0-x86_64.AppImage` is recommended (`chmod +x` and open it; every feature). The `.flatpak`
installs with `flatpak install --user`; some features are still untested there. Every file is GPG-signed (fingerprint above).

**New (all optional, off by default, in Requirements and about › Preferences):**
- **Notification area:** minimizing turns Ilmenyx into an icon near the clock (Open, Pause monitor, Quit). It only hides the window
  when the desktop shows a notification area (GNOME needs the AppIndicator extension).
- **Hot CPU alert:** a notification when the CPU stays above the limit (80 to 95 °C) for 20 seconds in a row; quick turbo spikes
  never trigger it.
- **New version alert (asked once):** checks GitHub releases once a day; the version in the sidebar becomes a download link.
- Help Center updated in all three languages; repository renamed to `ilmenyx-controller`; README in English and Portuguese.
