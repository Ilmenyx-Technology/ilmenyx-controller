**English below.**

O Ilmenyx agora se atualiza sozinho: baixa a versão nova, confere a assinatura e instala, com um clique.

> **Pré-lançamento.** Validado em hardware real, mas ainda não em todas as distros e GPUs. O que falta testar: `Sem_teste.md`.

## Qual baixar
| Arquivo | Para quem |
|---|---|
| `Ilmenyx-Controller-0.33.1-x86_64.AppImage` | **Recomendado.** Um arquivo só: `chmod +x Ilmenyx-Controller-0.33.1-x86_64.AppImage` e abrir. Todos os recursos. |
| `Ilmenyx-Controller-0.33.1-x86_64.flatpak` | Quem prefere Flatpak: `flatpak install --user Ilmenyx-Controller-0.33.1-x86_64.flatpak`. Alguns recursos ainda não foram testados nele (`docs/flatpak.md`). |
| `Ilmenyx-Controller-0.33.1-linux-x64.tar.gz` | Pacote em pasta (técnicos). |

Cada arquivo tem `.sha256` e assinatura GPG `.asc` (chave `ilmenyx-release-key.asc`, impressão digital
`3D97 1657 2A39 8DCD D0CF  F0EE 733D 2EC7 8436 DCE8`; como conferir: `docs/assinatura-gpg.md`). Fontes GPL que vão nos pacotes:
`OpenRGB-1.1-source.tar.gz`, `umu-launcher-1.4.4-source.tar.gz`, `python-xlib-0.33.tar.gz`.

**Já tem a 0.32 ou a 0.33.0?** Esta é a última vez que você atualiza à mão. No Flatpak: baixe o arquivo e rode
`flatpak install --user --reinstall Ilmenyx-Controller-0.33.1-x86_64.flatpak`. No AppImage: troque o arquivo pelo novo.

## Novidade
- **Atualizar agora:** quando sair uma versão nova, clique na versão no canto do menu lateral (ou em Verificar agora, nas Preferências).
  O Ilmenyx baixa o arquivo certo, confere a soma SHA-256 e a **assinatura GPG** contra a chave da Ilmenyx que vem dentro do app, e
  instala: troca o AppImage ou reinstala o Flatpak, só para o seu usuário. Se algo não conferir, nada é instalado. Depois, Reiniciar
  agora abre a versão nova. O pacote em pasta continua com a página de downloads.

## English

Ilmenyx now updates itself: it downloads the new version, checks its signature and installs it, in one click.

**Download:** `Ilmenyx-Controller-0.33.1-x86_64.AppImage` is recommended (`chmod +x` and open it; every feature). The `.flatpak`
installs with `flatpak install --user`; some features are still untested there. Every file is GPG-signed (fingerprint above).
Already on 0.32 or 0.33.0? This is the last manual update: `flatpak install --user --reinstall Ilmenyx-Controller-0.33.1-x86_64.flatpak`,
or replace the AppImage file.

**New:** **Update now**. When a new version is out, click the version in the corner of the sidebar (or Check now in Preferences).
Ilmenyx downloads the right file, checks the SHA-256 checksum and the **GPG signature** against the Ilmenyx key built into the app, and
installs it (replaces the AppImage or reinstalls the Flatpak, for your user only). If anything does not match, nothing is installed.
Restart now opens the new version. The folder package still uses the downloads page.
