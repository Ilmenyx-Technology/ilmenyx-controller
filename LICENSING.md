# Mapa de licenças do Ilmenyx

Política esclarecida pelo mantenedor em 2026-10-21 para contribuições próprias licenciáveis:
**uso como ferramenta em trabalho remunerado é permitido; vender o programa, cobrar pelo acesso
ou explorar seu código para criar produto/serviço pago não é autorizado**. Termos específicos em
LICENSE-ILMENYX.md. O conjunto não é anunciado como open source OSI por conter restrições comerciais.

| Material | Termos / alcance |
|---|---|
| upstream/ResetExplode/** | MIT original Gustavo (GustavoReset), inalterada; permite uso comercial |
| Partes anteriores MIT, algoritmos/copias/adaptações já disponibilizados sob MIT | LICENSE/avisos preservados; direitos anteriormente concedidos não são retirados |
| Contribuições próprias futuras identificadas/licenciáveis pelo titular | LICENSE-ILMENYX.md; uso instrumental profissional permitido, venda/acesso pago/derivação comercial restritos |
| Bibliotecas/assets/SDKs/drivers de terceiros | Termos de cada titular, não modificados por esta política |
| Marca/identidade visual | Não se presume registro/exclusividade; permissões próprias pendentes |

LICENSE conserva a MIT integral e avisos históricos. Não usar sua presença como única descrição
dos termos das contribuições futuras. Não presumir titularidade de pessoa jurídica ou cessões.

O novo Core/ValidationHtmlReport.cs e novas adições deste incremento em CLI/Sobre/docs/testes
seguem os termos próprios no que forem contribuições legitimamente licenciáveis. Componentes
preexistentes reutilizados mantêm seus direitos. Demais arquivos anteriores não foram
retroativamente restringidos nesta tarefa. Contribuições futuras devem registrar proveniência.

PENDENTE DE REVISÃO / BLOQUEIA PUBLICAÇÃO: identificar titulares, revisar fronteiras e texto
jurídico. Mudar o texto de um arquivo não revoga permissões MIT já concedidas, nem impede que
alguém reutilize o original MIT conforme seus termos. Não é parecer jurídico.
